## 区块、交易与状态

区块头 80 字节，数字小端编码，时间和 nonce 为 uint32。bits 必须是规范的正 256 位目标，满足本网络上限和候选父链预期难度，哈希满足 PoW。时间大于父链前 11 块的中位数，且不超过当前时间 2 小时。头同步验证高度、祖先和累计工作量。

最多 8,000,000 字节/块、20,000 笔交易/块。首笔是唯一 coinbase，输入脚本前 4 字节以小端提交高度，奖励不超过补贴加手续费。同块允许按顺序依赖前序交易，禁止重复输入、重复交易和覆盖现有输出。金额单项及交易总额不超过 `21,000,000 × 100,000,000`，使用整数及溢出检查。

交易版本只接受 0、1、101，最多 1,000,000 字节、10,000 输入、10,000 输出、每脚本 10,000 字节。版本 0/1 输出为 20 字节公钥哈希锁。花费这种锁使用 97 字节 Ed25519 解锁数据（64 字节签名、1 字节类型、32 字节公钥），必须匹配 UTXO 所有者。校验方式由被花费输出决定，不能由花费者任选。

版本 101 支持自定义脚本及 BIP65/BIP68/BIP112 风格锁定条件：绝对锁使用候选高度或父链 MTP；相对锁禁用位 bit31、时间类型 bit22、低 16 位数值，时间单位 512 秒。每个输入均执行锁定脚本，解锁脚本仅压栈。限制 201 个操作、1,000 栈元素、100 层条件嵌套、单个压栈元素 520 字节，移位范围 0..4096。`OP_CODESEPARATOR` 不支持。签名检查成本最多 1,000/交易、20,000/块，无序多签按 400 保守计费。这不是 Bitcoin Script 兼容承诺。

签名类型 ALL/NONE/SINGLE，可组合 `0x80` ANYONECANPAY；SINGLE 缺少对应输出时拒绝。交易 ID 必须与规范字节一致，反序列化拒绝非规范变长整数、越界字段、超限分配和尾随数据。

`BlockchainManager` 启动时加载全部区块头，从创世块累加工作量，在区块体齐全的分支中选出主链。同工作量时保留已应用的链尖。收到完整区块后，同一管理器增量比较候选分支与当前主链；预同步的区块头在对应区块体通过验证后才参与主链切换。

区块、撤销记录、UTXO、地址/交易/高度索引和链尖在一个同步 WAL 的 RocksDB WriteBatch 中提交，成功后才发布新链尖、清理交易池和广播。撤销记录保留完整来源高度、coinbase、脚本、金额及不存在状态；侧链按自己的父链视图验证。本地自动重组资源限制见运维手册。

## UDP 传输

类名包含 Quic，但线上是自定义 UDP 协议。握手修订号为 2，P2P 业务消息内部版本为 1，两者不同。

握手固定 293 字节，签名覆盖协议版本、网络、方向、连接/数据 ID、端点参数、临时交换公钥、时间、nonce 和响应回显 nonce。时间窗口 ±60 秒，重放记录保留 125 秒且有容量上限。连接与待握手数量有界，入站握手全局最多 50 次/秒，并有 IP/节点限流。

双方签名握手记录参与 HKDF-SHA256，派生独立方向的 AES-GCM 密钥。所有数据与控制帧使用认证信封，唯一序号 nonce、4096 包重放窗口。拒绝旧的明文控制帧、网络伪造的本地握手完成消息、与连接公钥不一致的业务 senderId。

全局在途发送/接收预留估算内存 96 MiB；完整消息队列 64 MiB/256 条，分批消费；每条业务消息最多 8,100,000 字节。每连接接收最多 16 消息，发送最多 32 消息并受 16 MiB 帧预算限制。连接关闭、完成、取消和过期均释放预留。交易池估算内存 64 MiB、TTL 72 小时、祖先最多 25 个；UTXO/交易/孤块缓存各估算 32 MiB。估算值不等于 JVM 实际 RSS，还需监控堆、直接及原生内存。
